# AI Virtual Keyboard

AI-powered virtual keyboard built with Python, OpenCV, and MediaPipe.

## Features

* Real-time hand tracking
* Finger gesture typing
* Virtual keyboard interface
* Space and Backspace support
* Contactless typing

## Installation

```bash
pip install -r requirements.txt
```

## Download Model

Download `hand_landmarker.task` and place it in the project root folder.

## Run

```bash
python main.py
```

## Controls

* Move index finger over a key
* Pinch thumb and index finger to press
* Press Q to quit

## Technologies

* Python
* OpenCV
* MediaPipe
* PyAutoGUI
